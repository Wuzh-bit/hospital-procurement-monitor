# 关键词扩展（首次建立步骤 4 参考）

目标：**只让用户提供一个“项目类型”词，AI 自动扩展并一次确认**，避免让用户逐个填写同义词/排除词。

## 用户输入

只问一个项目类型词，例如：互联网医院、医院信息化、医疗设备、检验试剂、智慧药房、远程医疗、医院信息系统、互联网护理……

不要要求用户提供同义词、排除词或公告类型。

## 扩展规则

1. **同义词（synonyms）**：项目类型词的中文常见表达、行业叫法、业务近义短语。
   - 来源：领域常识；对行业表达无把握时至多 1 次总搜索确认。
   - 约束：**不跨品类扩展**。项目类型是“互联网医院”，就不能扩出“医疗设备”；同义词必须与项目类型同一业务语义。
2. **排除词（exclude）**：与项目类型同音/近义但业务无关的干扰词（如“互联网医院”→“互联网宽带/专线/上网行为管理”）。默认**不添加**“办公家具/保洁/食堂”等通用无关品类——全局初筛已能排除，避免规则膨胀。
3. **优先公告类型（priority_notice_types）**：默认采用需求侧早介入信号：
   `需求调查 / 市场调研 / 参数征集 / 采购意向 / 需求征集 / 方案征集`
4. **栏目噪音（noise_link_texts）**：默认集（院内新闻/媒体聚焦/医院党建/资料下载等），来源确认时可按实际页面补充。

## 确认方式（批量）

把同义词、排除词、优先公告类型一次列表：

- 用户回复“全部确认” → 全部采纳；
- 用户指出增删（如“加 XX、去掉 YY”）→ 更新后再确认；
- 未确认不写入配置。

## 示例：项目类型“互联网医院”

同义词（实际使用效果良好）：

```
互联网诊疗 互联网医疗 互联网+医疗 互联网+医疗健康 互联网医疗健康 智慧医疗 智慧医院
在线复诊 在线问诊 线上问诊 线上复诊 远程医疗 远程会诊 远程门诊 互联网门诊 掌上医院
互联网处方 电子处方 在线处方 线上处方 互联网药房 在线药房 互联网护理 在线护理
互联网挂号 在线挂号 云医院 在线诊疗 线上诊疗 互联网健康服务 数字健康 互联网+健康
健康云平台 线上医疗服务 互联网医院平台 互联网医疗平台
```

排除词（近义干扰）：

```
互联网宽带 互联网专线 上网行为管理
```

优先公告类型：

```
需求调查 市场调研 参数征集 采购意向 需求征集 方案征集
```

栏目噪音（默认集，可按页面补充）：

```
院内新闻 媒体聚焦 新闻公告 医疗技术临床应用 资料下载 医院党建 医患真情 团员青年
```

## 常见项目类型快速对照

| 项目类型 | 同义词要点 | 典型排除词 |
|---|---|---|
| 互联网医院 | 在线复诊/远程会诊/掌上医院/电子处方… | 互联网宽带/专线/上网行为管理 |
| 医院信息化/HIS | 医院信息系统/智慧医院/信息化建设… | 信息化办公设备/耗材 |
| 医疗设备 | 医疗设备采购/医学装备/器械… | 检验试剂（若单独跟踪） |
| 检验试剂 | 体外诊断/检验耗材/IVD… | 医疗设备（若单独跟踪） |

> 表格仅为提示方向，具体以用户确认的项目类型语义为准，仍遵守“不跨品类扩展”约束。
